# VGC: Vickers Gray-level Compression

This repository accompanies the manuscript **“Unsupervised Gray-Level Compression for Improved Automatic Measurement of Vickers Indentations”**, submitted to *Measurement*.

## Overview

Vickers Gray-level Compression (VGC) is an unsupervised image preprocessing method designed to improve automatic measurement of Vickers indentations. It compresses image gray levels to suppress surface texture and local intensity fluctuations while preserving the main indentation structure.

VGC operates on individual images without annotated data or a pretrained model and can be integrated into existing indentation measurement pipelines.
